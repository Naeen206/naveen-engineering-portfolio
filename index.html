Embedded Systems & Hardware Status: Tested & Verified

Smart Energy Audit System Using Microwave Occupancy Detection

An ESP32-based engineering project combining microwave occupancy detection with electrical monitoring to explore occupancy-aware energy management.

This project investigates intelligent energy conservation by measuring electrical parameters (voltage and current) alongside human presence. Unlike standard infrared (PIR) sensors that fail when occupants are stationary, the Doppler microwave sensor provides continuous presence tracking through physical obstructions. The ESP32 processes real-time telemetry and automates test load switching through an optocoupler-isolated relay module.

Technical Project Overview

Smart Energy Audit System Using Microwave Occupancy Detection

Concept & Motivation: Energy efficiency in modern commercial and educational environments often suffers from false vacancy indications by conventional passive infrared (PIR) sensors when occupants are typing or sitting still. This system integrates the RCWL-0516 microwave Doppler radar sensor, operating at ~3.18 GHz, which penetrates non-conductive barriers and detects micro-movements accurately.

Hardware Testing & Setup:

  • Microcontroller: ESP32 executing C/Embedded C firmware to sample analog transducer outputs.
  • Occupancy Sensing: RCWL-0516 digital output pin interfaced with ESP32 GPIO with debouncing logic.
  • Current & Voltage Telemetry: ACS712 current transducer and ZMPT101B voltage transformer calibrated to calculate active electrical power.
  • Isolation & Switching: Optocoupler-isolated relay module connected to safely actuate the 230V AC LED bulb test load.
Note: All circuit telemetry has been verified on benchtop experimental setups. Firmware and test code are maintained in my GitHub repository.
